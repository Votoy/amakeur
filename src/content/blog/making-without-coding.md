I am not a programmer. I still ship things.

That sentence used to feel like a confession. Now it feels like a method. The tools changed. The craft did not.

## What “making” means here

Making is deciding what should exist, then refusing to abandon it when the first attempt looks stupid. Coding is one way to get there. Natural language, AI, design systems, and stubborn iteration are others.

## A working loop

1. **Name the feeling.** Not the feature. The feeling.
2. **Describe it until a machine can almost taste it.**
3. **Ship a thin slice.** Ugly is fine. Empty is not.
4. **Sit with it for a week.** Edit the sentence, not the resume.

## Serious about making

Amateur at code is not an excuse for sloppy work. It is a reminder that code is not the product. The product is the moment someone opens the thing and thinks: *this understands me*.

If you are also making without coding — welcome. We are not faking expertise. We are practicing craft from the side door.
